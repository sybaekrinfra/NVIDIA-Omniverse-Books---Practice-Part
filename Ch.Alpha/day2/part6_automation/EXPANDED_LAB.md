# D2P6 확장 실습 · 반복 실험과 결과 기록

이 실습은 기존 Part 시간 안에서 선택해 진행합니다. 기존 기본 실습을 10분, 확장 활동을 5분으로 배분합니다. 도전 과제는 조기 완료자 또는 교육 후 복습용입니다. 확장 활동을 기존 실습 뒤에 모두 추가하지 않습니다.

## 상황과 목표

**자동 실행 결과 해석**을 수행합니다. 시작 파일은 `checkpoints/03_physics.usda`입니다. Python 예제는 Script Editor에서 `00_start_here.py`를 먼저 실행합니다. 원본 체크포인트는 저장하지 않고 결과를 outputs에 보관합니다.

## 가이드 실습

1. 04_automate_simulation.py로 질량 두 조건을 실행한다.
2. simulation_runs.csv의 2행과 2초 종료 시간을 확인한다.
3. 로그가 측정 위치가 아닌 실행 조건 기록임을 구별한다.
4. 중간 Stop과 06_stop_tasks.py를 사용한 취소 동작을 확인한다.

## 생각해 보기

CSV가 생성되면 낙하 검증을 모두 통과한 것인가?

팀원과 예상 결과를 적고 관찰 결과를 비교합니다. 해설은 강사와 함께 확인합니다.

## 자주 발생하는 문제

증상: 조건 로그를 측정 데이터로 오인

복구: 보고서의 각 열이 무엇을 기록하는지 설명한다.

## 선택 도전

동일 조건 반복 시 파일을 보존하는 이름 규칙과 비교표를 설계한다.

## 제출 및 통과 기준

실행 CSV와 사람이 작성한 관찰 열를 제출합니다. 결과만 보여주지 않고 설정 또는 데이터가 결과에 영향을 준 이유를 한 문장으로 설명하면 완료합니다.
