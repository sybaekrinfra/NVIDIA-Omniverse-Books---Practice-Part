# Day 2 Part 6 · 객체 속성과 시뮬레이션 자동화

배정 30분: 설명 15분, 실습 15분. 입력: `03_physics.usda`, `04_automate_simulation.py`.

## 목표와 개념

반복문으로 실험 조건을 바꾸고 Timeline으로 재생을 제어합니다. `await`는 UI 이벤트 루프에 제어를 돌려줍니다. 앱 업데이트 횟수와 물리 시뮬레이션 시간이 반드시 같지는 않습니다.

## 따라하기

1. 03 장면을 엽니다. 다른 작업은 끝내고 Timeline을 Stop합니다.
2. 04 코드를 읽어 질량 목록 `(1.0, 5.0)`, 높이 1.5m, 시뮬레이션 시간 2초 조건을 찾습니다.
3. 04를 실행합니다. 각 질량에서 작업물이 떨어지고 멈추는 모습을 관찰합니다.
4. `outputs/simulation_runs.csv`를 텍스트 편집기로 확인합니다. 질량, 초기 높이, 종료 시뮬레이션 시간이 2행으로 기록됩니다.
5. observation 열에 “바닥에 정지” 등 직접 관찰한 결과를 적고 별도 이름으로 보관합니다.
6. 조기 완료자는 높이를 2m로 바꾸어 다시 실험합니다. 이전 CSV는 먼저 다른 이름으로 저장합니다.

## 완료 확인

두 실험의 조건이 기록되고 질량이 커져도 같은 중력·초기 높이에서 낙하가 빨라진다고 단정하지 않으면 통과합니다. 이 로그는 실행 조건 기록이며 위치·속도 측정 로그가 아닙니다.

중지는 06 스크립트를 사용합니다. 타임아웃이면 PhysicsScene, Play 상태와 앱 성능을 확인하고 수동 Play 관찰로 대체합니다.
