# D2P3 확장 실습 · 질량과 높이의 비교 실험

이 실습은 기존 Part 시간 안에서 선택해 진행합니다. 기존 기본 실습을 9분, 확장 활동을 6분으로 배분합니다. 도전 과제는 조기 완료자 또는 교육 후 복습용입니다. 확장 활동을 기존 실습 뒤에 모두 추가하지 않습니다.

## 상황과 목표

**A/B/C 낙하 가설 세우기**을 수행합니다. 시작 파일은 `checkpoints/06_physics_comparison.usda`입니다. Python 예제는 Script Editor에서 `00_start_here.py`를 먼저 실행합니다. 원본 체크포인트는 저장하지 않고 결과를 outputs에 보관합니다.

## 가이드 실습

1. A는 1kg·1.5m, B는 5kg·1.5m, C는 1kg·2.5m임을 확인한다.
2. 재생 전에 먼저 바닥에 닿는 순서를 예측한다.
3. Play하고 A/B와 C를 비교한다.
4. Stop 후 같은 조건으로 다시 확인하고 한 번의 화면 관찰 한계를 적는다.

## 생각해 보기

A와 B는 질량이 다른데 왜 비슷하게 떨어질까?

답을 보기 전에 팀원과 예상 결과를 적습니다. [강사용 해설](../../instructor/EXPANDED_ANSWERS.md#d2p3)에서 비교할 수 있습니다.

## 자주 발생하는 문제

증상: 화면 프레임 수를 정확한 물리 시간으로 간주

복구: 정량 비교에는 시뮬레이션 시간과 측정 방법이 필요함을 설명한다.

## 선택 도전

바닥 접촉까지의 이상적 시간 sqrt(2*(z0-0.1)/9.81)을 계산하고 solver 관찰과 차이를 설명한다.

## 제출 및 통과 기준

예측·관찰·설명 세 항목를 제출합니다. 결과만 보여주지 않고 설정 또는 데이터가 결과에 영향을 준 이유를 한 문장으로 설명하면 완료합니다.
