# D2P7 확장 실습 · 장비 상태와 데이터 품질

이 실습은 기존 Part 시간 안에서 선택해 진행합니다. 기존 기본 실습을 30분, 확장 활동을 22분으로 배분합니다. 도전 과제는 조기 완료자 또는 교육 후 복습용입니다. 확장 활동을 기존 실습 뒤에 모두 추가하지 않습니다.

## 상황과 목표

**세 장비의 정상·이상·결측·지연 표시**을 수행합니다. 시작 파일은 `checkpoints/08_multi_equipment.usda`입니다. Python 예제는 Script Editor에서 `00_start_here.py`를 먼저 실행합니다. 원본 체크포인트는 저장하지 않고 결과를 outputs에 보관합니다.

## 가이드 실습

1. 기존 단일 장비 실습으로 정상·주의·경보를 먼저 확인한다.
2. 08을 열고 10_multi_equipment.py를 실행한다.
3. 2초 E03의 UNKNOWN, 6초 E02의 STALE을 확인한다.
4. outputs/multi_equipment_report.csv 12행을 확인한다.
5. 다른 선택 경로로 09_thermal_field와 11_thermal_field.py를 열어 baseline/hotspot 분포를 비교한다. 수업에서는 둘 중 하나를 선택한다.

## 생각해 보기

마지막 수치가 정상이라면 오래된 데이터도 녹색으로 표시해도 될까?

답을 보기 전에 팀원과 예상 결과를 적습니다. [강사용 해설](../../instructor/EXPANDED_ANSWERS.md#d2p7)에서 비교할 수 있습니다.

## 자주 발생하는 문제

증상: 결측값을 0으로 채워 정상으로 판정

복구: UNKNOWN 상태로 표시하고 이전 숫자는 Block하여 남지 않게 한다.

## 선택 도전

팀 과제에서 운영 상태와 데이터 품질을 나누고 결측값 처리·범례·출처를 함께 제시한다.

## 제출 및 통과 기준

12행 보고서 또는 온도장 비교 화면, 범례, 데이터 출처를 제출합니다. 결과만 보여주지 않고 설정 또는 데이터가 결과에 영향을 준 이유를 한 문장으로 설명하면 완료합니다.
