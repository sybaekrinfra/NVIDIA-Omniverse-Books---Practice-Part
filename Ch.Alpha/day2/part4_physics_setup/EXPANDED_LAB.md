# D2P4 확장 실습 · 바닥 통과 오류 복구

이 실습은 기존 Part 시간 안에서 선택해 진행합니다. 기존 기본 실습을 15분, 확장 활동을 8분으로 배분합니다. 도전 과제는 조기 완료자 또는 교육 후 복습용입니다. 확장 활동을 기존 실습 뒤에 모두 추가하지 않습니다.

## 상황과 목표

**누락된 충돌 설정 찾기**을 수행합니다. 시작 파일은 `checkpoints/11_fault_collision.usda`입니다. Python 예제는 해당 파일 전체를 Script Editor에서 바로 실행합니다. 원본 체크포인트는 저장하지 않고 결과를 outputs에 보관합니다.

## 가이드 실습

1. 11 장면의 Play 결과를 짧게 관찰하고 Stop한다.
2. 08 진단에서 ground_collider 항목을 확인한다.
3. Ground의 physics:collisionEnabled를 True로 바꾼다.
4. Play하여 접촉을 확인하고 수정 전후 화면을 남긴다.

## 생각해 보기

Collider API가 붙어 있는데도 통과할 수 있는가?

팀원과 예상 결과를 적고 관찰 결과를 비교합니다. 해설은 강사와 함께 확인합니다.

## 자주 발생하는 문제

증상: Pause 상태에서 수정해 초기 조건이 혼동됨

복구: Stop 후 다시 실행한다.

## 선택 도전

Workpiece의 rigidBodyEnabled=False와 바닥 Collider=False 증상을 비교한다.

## 제출 및 통과 기준

증상·원인·수정 속성·재검증 결과를 제출합니다. 결과만 보여주지 않고 설정 또는 데이터가 결과에 영향을 준 이유를 한 문장으로 설명하면 완료합니다.
