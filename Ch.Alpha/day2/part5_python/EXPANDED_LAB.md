# D2P5 확장 실습 · Python 반복문과 일괄 배치

이 실습은 기존 Part 시간 안에서 선택해 진행합니다. 기존 기본 실습을 18분, 확장 활동을 12분으로 배분합니다. 도전 과제는 조기 완료자 또는 교육 후 복습용입니다. 확장 활동을 기존 실습 뒤에 모두 추가하지 않습니다.

## 상황과 목표

**6개에서 12개 작업물로 확장**을 수행합니다. 시작 파일은 `checkpoints/07_batch_layout.usda`입니다. Python 예제는 해당 파일 전체를 Script Editor에서 바로 실행합니다. 원본 체크포인트는 저장하지 않고 결과를 outputs에 보관합니다.

## 가이드 실습

1. 09_batch_layout.py를 실행하여 2행×3열=6개를 확인한다.
2. ROWS=3, COLUMNS=4, SPACING_M=0.45로 바꾼다.
3. 다시 실행해 12개인지 확인한다. 이전 배열이 남지 않는다.
4. 경로와 training:part_id가 중복되지 않는지 확인한다.
5. 간격이 0.25m보다 작을 때 오류를 내는 이유를 설명한다.

## 생각해 보기

실행할 때마다 6개씩 추가되는 것과 최종 6개를 유지하는 것 중 재실행에는 무엇이 유리할까?

팀원과 예상 결과를 적고 관찰 결과를 비교합니다. 해설은 강사와 함께 확인합니다.

## 자주 발생하는 문제

증상: 다른 Stage에서 Batch를 덮어씀

복구: 07 전용 체크포인트를 사용하고 기존 작업을 보존한다.

## 선택 도전

개수를 바꿔도 결과를 점검할 수 있도록 rows*columns 예상 개수를 출력한다.

## 제출 및 통과 기준

6개/12개 화면, 경로 목록, 재실행 개수를 제출합니다. 결과만 보여주지 않고 설정 또는 데이터가 결과에 영향을 준 이유를 한 문장으로 설명하면 완료합니다.
