# Day 2 Part 1 · Simulation Ready Asset 제작하기

배정 30분: 설명 15분, 실습 15분. 입력: `checkpoints/02_structured.usda`.

## 목표와 개념

Simulation Ready는 목적에 맞는 형상·단위·충돌·질량 등의 준비 상태입니다. 이 수업은 단순 작업물 낙하를 위한 최소 준비를 다룹니다. 완성된 산업 장비 검증이나 인증을 수행하지 않습니다.

## 따라하기

1. 02를 열고 바닥·장비·작업물·상태 표시구를 찾습니다.
2. 01 스크립트를 실행해 meter / Z-up을 확인합니다.
3. 다음 표를 실습 기록지에 복사하고 현재 값과 필요한 변경을 적습니다.

| 항목 | 이번 실습의 목표 |
|---|---|
| 기준 단위 / 축 | 1m / Z-up |
| 장비 CAD | 고정된 시각 참조, 관절·충돌 미설정 |
| 작업물 | 한 변 0.2m, 중심 z=1.5m, 질량 1kg |
| 바닥 | 윗면 z=0m, 정적 Collider |
| 중력 | -Z 방향, 9.81m/s² |
| 상태 표시구 | 물리와 독립된 시각 객체 |

4. Workpiece와 Ground에 아직 물리 API가 없는지 Property 또는 텍스트로 확인합니다.

## 완료 확인

“보인다”와 “물리 시뮬레이션이 준비되었다”의 차이를 설명하고 누락 속성을 2개 이상 적습니다. 실제 물리 설정은 Part 4에서 추가합니다.
