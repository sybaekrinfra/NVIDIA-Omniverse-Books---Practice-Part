# D2P1 확장 실습 · 실습 목적에 맞는 준비도 검사

이 실습은 기존 Part 시간 안에서 선택해 진행합니다. 기존 기본 실습을 8분, 확장 활동을 7분으로 배분합니다. 도전 과제는 조기 완료자 또는 교육 후 복습용입니다. 확장 활동을 기존 실습 뒤에 모두 추가하지 않습니다.

## 상황과 목표

**설정 전후 진단표 비교**을 수행합니다. 시작 파일은 `checkpoints/02_structured.usda`입니다. Python 예제는 Script Editor에서 `00_start_here.py`를 먼저 실행합니다. 원본 체크포인트는 저장하지 않고 결과를 outputs에 보관합니다.

## 가이드 실습

1. 02에서 08_check_readiness.py를 실행하고 CHECK 항목을 적는다.
2. 03_physics를 열고 동일 검사를 실행한다.
3. 물리 속성을 추가하면서 PASS가 된 항목을 연결한다.
4. 검사 범위가 작업물 낙하 실험이라는 점을 기록한다.

## 생각해 보기

모든 항목 PASS면 실제 장비의 동작이 검증된 것인가?

답을 보기 전에 팀원과 예상 결과를 적습니다. [강사용 해설](../../instructor/EXPANDED_ANSWERS.md#d2p1)에서 비교할 수 있습니다.

## 자주 발생하는 문제

증상: 정적 검사 PASS를 물리 실행 성공으로 오인

복구: 정적 검사와 Play 관찰을 별도 증거로 기록한다.

## 선택 도전

실제 프로젝트의 질량·마찰·관성 값은 어떤 자료로 검증해야 할지 조사 계획을 작성한다.

## 제출 및 통과 기준

02와 03의 진단 결과 비교표를 제출합니다. 결과만 보여주지 않고 설정 또는 데이터가 결과에 영향을 준 이유를 한 문장으로 설명하면 완료합니다.
