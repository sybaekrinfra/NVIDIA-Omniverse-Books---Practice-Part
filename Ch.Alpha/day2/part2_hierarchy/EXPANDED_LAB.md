# D2P2 확장 실습 · 원본 CAD와 시뮬레이션 역할 분리

이 실습은 기존 Part 시간 안에서 선택해 진행합니다. 기존 기본 실습을 18분, 확장 활동을 12분으로 배분합니다. 도전 과제는 조기 완료자 또는 교육 후 복습용입니다. 확장 활동을 기존 실습 뒤에 모두 추가하지 않습니다.

## 상황과 목표

**원본 물리와 override 확인**을 수행합니다. 시작 파일은 `checkpoints/03_physics.usda`입니다. Python 예제는 해당 파일 전체를 Script Editor에서 바로 실행합니다. 원본 체크포인트는 저장하지 않고 결과를 outputs에 보관합니다.

## 가이드 실습

1. 제공 CAD USD의 원본을 읽기 전용 관찰하여 link와 Joint 경로를 찾는다.
2. 공통 01 장면에 기존 물리를 제거하는 override가 있음을 텍스트로 확인한다.
3. 03에서 움직이는 대상이 Workpiece 하나인지 확인한다.
4. 시각 자산과 충돌 자산을 별도로 관리하는 장점을 설명한다.

## 생각해 보기

CAD 전체에 Rigid Body를 한꺼번에 추가하면 무엇이 문제가 될까?

팀원과 예상 결과를 적고 관찰 결과를 비교합니다. 해설은 강사와 함께 확인합니다.

## 자주 발생하는 문제

증상: 원본 USD를 직접 수정

복구: 원본을 재복사하고 수정은 상위 Layer에서 수행한다.

## 선택 도전

설비·이동 부품·센서·표시구를 분리한 계층 초안을 만든다.

## 제출 및 통과 기준

원본 CAD와 공통 장면의 활성 물리 대상 비교를 제출합니다. 결과만 보여주지 않고 설정 또는 데이터가 결과에 영향을 준 이유를 한 문장으로 설명하면 완료합니다.
