# 다른 실습과 함께 사용하기

## 실행 환경과 폴더

Ch.Alpha의 Python은 **Isaac Sim Script Editor**에서 실행합니다. Ch.Beta의 Python과 셸 명령은 **ROS 2 환경을 활성화한 시스템 터미널**에서 실행합니다. 파일 실행 위치가 서로 다릅니다.

이동할 때 Ch.Alpha 전체를 복사하여 checkpoints와 shared의 상대 위치를 유지하세요. 04·05·10·11·13은 열린 장면으로부터 Ch.Alpha를 찾습니다. 장면이 임시 Stage이거나 폴더 밖에 저장되어 자동 탐색이 안 되면 실행할 파일의 ROOT를 지정하세요. 각 스크립트는 00 초기화 없이 사용할 수 있습니다.

기본 실습은 `/World/Workpiece`, `/World/Ground`, `/World/Equipment` 등의 경로와 meter·Z-up 장면을 전제로 합니다. 임의 CAD 장면에서 곧바로 작동하는 범용 도구는 아닙니다. 다른 프로젝트에서는 코드의 대상 경로·단위·형상을 함께 확인하세요.

## Ch.Beta로 넘어갈 때

1. Alpha에서 진행 중인 작업은 `06_stop_tasks.py`로 중단하고 결과를 저장합니다.
2. ROS 2 Bridge와 명령 구독 그래프가 준비된 로봇 장면을 엽니다.
3. Beta 설정의 입력 토픽·출력 토픽·관절 이름을 그 장면에 맞춥니다.
4. 기록 → 기록 종료 → 재생 순으로 진행합니다. 실시간 중계기와 직접 재생기를 같은 명령 토픽에 동시에 연결하지 않습니다.

Alpha의 `12_joint_drive.usda`는 **Z축 1관절 개념 실습**입니다. ROS 그래프가 없고 Beta의 기본 `joint1`~`joint6` 구성과도 다릅니다. 그대로 연결되는 6축 로봇 예제가 아닙니다. Alpha의 BX200L은 공통 장면에서 시각 참고용으로 사용합니다.

## 결과와 배포

- Alpha 결과는 outputs, Beta 기록은 bag에 생성되며 Git에서 제외됩니다.
- 같은 출력 이름으로 다시 실행하면 Alpha 결과를 덮어쓸 수 있으므로 제출할 때 파일 이름을 구별하세요. Beta 기록 스크립트는 기존 bag 경로를 거부합니다.
- 다른 반에 배포할 때 Agents 폴더와 개인 결과물을 포함하지 않습니다. 로컬 폴더를 통째로 압축하는 대신 반영 완료된 Git 배포본을 사용하세요.
- Alpha의 합성 CSV, Beta의 모의 발행기, 실제 장비 기록은 출처를 구별하여 표시합니다.

Kit-CAE 자료는 별도의 `omni.cae.kit` 환경과 공식 샘플 데이터를 사용합니다. Alpha의 합성 온도장이나 Beta의 ROS 토픽만으로 Kit-CAE 네 예제를 실행할 수는 없습니다.
