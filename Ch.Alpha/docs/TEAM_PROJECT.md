# 팀별 미니 프로젝트

Day 2 Part 7의 선택 실습 22분을 사용합니다. 데이터 담당·USD 담당·검증 담당을 나누되 2인 팀은 역할을 겸합니다. 첫 3분 역할 분담, 10분 수정/실행, 5분 검증, 4분 설명으로 진행합니다. 두 트랙 중 하나만 수행합니다.

## A. 장비 상태 모니터링

입력: `08_multi_equipment.usda`, `multi_equipment.csv`, `10_multi_equipment.py`.

1. 3개 장비의 0·2·4·6초 입력을 읽고 예상 상태를 적습니다.
2. 원본 실행으로 보고서 12행과 표시 상태를 확인합니다.
3. CSV 복사본에서 E03의 결측을 유효 값으로 바꾸고 E02의 마지막 sample_time을 6으로 바꿉니다. 스크립트 입력 경로도 복사본으로 바꿉니다.
4. 재실행해 UNKNOWN과 STALE이 정상적으로 해소되는지 확인합니다.
5. 알람 상태와 데이터 품질을 함께 운영하려면 어떤 표시가 더 필요한지 한 문장으로 제안합니다.

제출: 변경 CSV, 전후 상태표, 화면 2장, 결과 USD. 실제 계측값이라고 표현하지 않습니다.

## B. 온도 분포 검토

입력: `09_thermal_field.usda`, `thermal_baseline.csv`, `thermal_hotspot.csv`, `11_thermal_field.py`.

1. baseline/hotspot을 범례 20~100°C로 각각 표시합니다.
2. 최대값과 위치(face_id)를 비교합니다. hotspot의 최대는 face_id=15, 95°C입니다.
3. 같은 hotspot에서 범례를 20~60°C로 바꿔 포화되는 면을 확인합니다.
4. 공정 비교용 결과는 동일한 범례 20~100°C로 되돌려 저장합니다.
5. 실제 CAE 결과를 가져올 때 필요한 면 매핑·단위·좌표계·field 출처를 적습니다.

제출: 두 분포 화면, 사용 범례, 최대값과 face_id, 데이터 출처. 이 실습은 합성 scalar field 시각화이며 CAE 계산은 하지 않습니다.

- 숫자·판정·색의 의미가 일치하는가?
- 이 결과로 말할 수 없는 것은 무엇인가?
