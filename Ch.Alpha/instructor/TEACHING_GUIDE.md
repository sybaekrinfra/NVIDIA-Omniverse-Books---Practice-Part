# 강사 운영·정답·평가

## 교육 전

앱 버전을 교육장 전체에서 통일합니다. 01→03 장면 열기, 물리 낙하, Python 자동화, CSV 재생, 결과 재열기를 동일 PC에서 한 번 완주하고 VALIDATION 리허설표에 기록합니다. CAD Converter와 Measure/Pivot/Section은 선택한 앱에서 직접 확인합니다. Nucleus 사용 여부를 확정하고 미준비 시 로컬 분업 경로를 안내합니다.

기존 자료에는 ROS·로봇·센서 교육이 많으므로 MATERIAL_MAP의 해당 슬라이드만 진행합니다. 특히 6H 자료의 Joint/Drive, Isaac의 Articulation, 심화의 ROS/RL을 본 수업의 선수 지식으로 요구하지 않습니다.

## 공통 운영

- 강사가 먼저 한 단계만 시연하고 교육생이 같은 단계의 완료 화면을 보여주게 합니다.
- 경로·숫자·문자열을 설명한 뒤 Python 코드를 실행합니다. 초급자에게 빈 파일부터 전체 코드를 작성하도록 요구하지 않습니다.
- UI 및 USD 기본 실습이 지연되면 Variant/Inherits/Specializes와 CAE 선택 설명을 줄입니다. 필수 최종 CSV 재생을 남겨둡니다.
- 파일 손상·구조 차이는 체크포인트로 복구합니다. 수업 중 복잡한 CAD hierarchy 수정을 디버깅하지 않습니다.
- 모든 학습자에게 정확한 같은 프레임 낙하 시간이나 solver 결과를 요구하지 않습니다.

## 평가 제안: 10점

| 항목 | 점수 | 통과 증거 |
|---|---:|---|
| USD 구조·참조 | 2 | 파일/Prim 경로를 구별하고 패키지 재열기 성공 |
| CAD 및 단위 | 2 | 실제 변환 여부 기록, 축·단위·크기 설명 |
| 기본 물리 | 2 | 작업물 낙하 및 바닥 접촉, 속성 역할 설명 |
| Python 자동화 | 2 | 값 변경 성공, 두 조건 로그와 관찰 기록 |
| 가상 상태 표시 | 2 | 상태 판정과 색 일치, 합성 데이터 범위 설명 |

6점 이상과 최종 가상 상태 표시 완료를 기초 목표 달성 기준으로 제안합니다. 점수는 학교의 공식 평가 기준이 아닙니다. CAD 변환기·Nucleus 미준비는 교육생 감점 사유로 삼지 않습니다.

## 통합 강의와 확장 문제 운영

기존 PPT는 보존하고 [60장 통합 강의](../presentations/README.md)를 새로 구성했습니다. Python 기본 문법·실행 순서, CSV 데이터 규칙, 상태 임계값, CAD 단위 검증을 실습 파일과 연결했습니다. PPT 발표자 노트에 설명과 진단 질문을 넣었으며 [별도 원고](../presentations/LECTURE_NOTES.md)도 제공합니다.

[확장 운영표](../docs/EXPANSION_GUIDE.md)의 기본·확장 시간을 합하면 각 Day의 실습 180분입니다. 확장을 추가 수업으로 모두 진행하지 않습니다. 느린 반은 기본 과제와 복구에 집중하고, 빠른 반은 비교 조건과 오류 문제를 선택합니다. Day 2 Part 7의 팀 과제는 다중 장비 상태 또는 합성 온도 분포 중 하나만 선택합니다. [확장 예상 답안](EXPANDED_ANSWERS.md)을 함께 사용합니다.
