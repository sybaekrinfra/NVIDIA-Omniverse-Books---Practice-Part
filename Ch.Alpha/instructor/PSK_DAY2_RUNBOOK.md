## 수업 운영 원칙

설명은 한 번에 8~10분, 그다음 조작·예측·비교·짝 설명으로 전환합니다. 개발자가 아닌 교육생에게 빈 편집창에서 코드를 작성하도록 요구하지 않습니다. GUI 우선, 제공 코드 실행은 보조강사가 지원합니다. 조작자와 기록자를 교대하고 조기 완료자에게만 추가 미션을 줍니다.

아래 표의 설명/시연 100분, 실습/기록/발표 260분은 **이번 편성 제안**입니다. 첨부 Agenda가 실습 비율을 규정한 것은 아닙니다. ROS 시연 준비 여부에 따라 배정 시간 안에서 대체 경로를 사용합니다.

- 5분: 09 온도장 두 CSV, 07 배치 6→12→6, 결과 저장·재열기.
- 5분: 준비된 ROS 환경에서 실제 topic과 메시지 확인. 실패하면 아래 대체 활동 확정.

## ROS 2 시연 준비

이 패키지는 ROS 2 배포판이나 Bridge를 자동 설치하지 않습니다. 기존 저장소의 [Ch.4 Dofbot ROS2 장면](../../Ch.4/dofbot_v2/dofbot_ros2.usd)과 [중계 스크립트](../../Ch.4/dofbot_relay.sh)를 참고하되, 교육장에 이미 검증된 환경을 우선 사용합니다. Ch.Alpha만 복사한 경우 상위 Ch.4/Ch.6 자료는 포함되지 않으므로 강사 PC에는 저장소 전체가 필요합니다.

1. 설치된 Isaac Sim 버전에 맞는 ROS 2 Bridge 확장·ROS 환경·통신 설정을 준비합니다. 사용한 앱/ROS 버전과 topic 이름을 아래에 기록합니다.
2. 제공 로봇 장면을 열고 Play, Bridge 활성 여부를 확인합니다.
3. 터미널에서 `ros2 topic list`로 실제 이름을 찾고 `ros2 topic info`, `ros2 topic echo <topic> --once`로 발행자·메시지를 확인합니다.
4. 교육 중에는 검증한 관측 경로부터 시연합니다. 중계 스크립트는 명령을 발행하므로 의도한 시뮬레이터 topic을 확인하고 실행합니다. 단순 echo 성공과 명령 제어 성공을 구분합니다.
5. 연결되지 않으면 다음 **가상 예시**로 해석 활동을 진행합니다. 실제 로그로 소개하지 않습니다.

```yaml
# 교육용 예시: 회전 관절 2개, position 단위 rad
name: [joint_1, joint_2]
position: [0.0, 0.52]
velocity: [0.0, 0.0]
effort: []
```

질문: 두 번째 관절은 약 몇 도인가? → 약 30도. name 순서가 바뀌면 position의 의미는? → 인덱스로 대응하므로 함께 확인. 상태 수신만으로 제어를 확인했는가? → 아니다.

대체 45분: 신호 흐름 그리기 10분, 메시지 대응 10분, 토픽 오류 진단 10분, 실습 7 배치 예습 15분. 실제 연결 미실시를 기록합니다.

## 빠른 팀과 느린 팀을 함께 운영하기

- 10분 남음: 추가 미션 A 또는 B. 하나의 변수만 바꿔 원인과 결과를 설명.
- 20분 남음: 추가 미션 C. 데이터 품질과 경보를 구별.
- 30분 남음: 추가 미션 D. 두 화면과 운영 제안으로 결과 발표.
- 진행이 15분 지연: 실습 2는 정상본과 비교로 단축하고 실습 4는 강사 시연으로 진행. 핵심 낙하·오류 복구·온도 비교·저장은 유지.
- 오후 시연 환경 실패: 미션 C 또는 D로 전환. 기능을 실행한 것처럼 수료 기록에 남기지 않기.

미션은 정규 시간에 모두 추가하는 숙제가 아닙니다. 기본 완료 후 남은 시간을 채우는 선택 과제입니다.

## 해설과 확인 질문

| 활동 | 기대 답 / 관찰 | 오해를 바로잡는 질문 |
|---|---|---|
| 구조 검수 | Equipment와 Workpiece는 별도 역할; Reference는 외부 자산 구성 | 부모를 움직이면 어느 자식이 따라오는가? |
| 크기 오류 | Equipment의 잘못된 Scale을 수정 | metersPerUnit만 바꾸면 숫자 좌표도 환산되는가? |
| 낙하 | 같은 높이 A/B의 자유낙하는 질량만으로 차이가 나지 않음 | 공기 저항이 없는 이 모델을 현실의 모든 물체에 일반화할 수 있는가? |
| 바닥 통과 | CollisionAPI 존재뿐 아니라 collisionEnabled 확인 | Pause와 Stop의 차이는? |
| Joint·Drive | Joint는 허용 운동/제약, Drive는 목표 추종; stiffness=0이면 위치 복원력 없음 | 목표값과 관측 각도는 항상 즉시 같은가? |
| Inertia | 회전에 대한 질량 분포의 영향; 이 실습은 형상 기반 추정 | 같은 질량의 긴 막대와 짧은 막대 회전 반응은 같은가? |
| 온도장 | baseline 30~45, hotspot 30~95°C, 동일 범례 | 색만 보고 온도를 판단해도 되는가? |
| 배치 | 6→12→6, 교육 전용 Batch 경로 교체 | 작업자 수작업과 자동화에서 공통 검수 항목은? |
| Replicator | RGB는 모습, bbox는 영역, segmentation은 픽셀별 분류 | 보기 좋은 사진이 곧 좋은 학습 데이터인가? |

관찰 결과가 예상과 다르면 오류로 단정하지 말고 초기 조건·실행 상태·화면 관찰 한계를 먼저 확인합니다. 화면 프레임과 물리 시간을 혼동하지 않습니다.
