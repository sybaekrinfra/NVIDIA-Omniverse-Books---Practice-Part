# D1P1 확장 실습 · 교육 목표와 장비 데이터

이 실습은 기존 Part 시간 안에서 선택해 진행합니다. 기존 기본 실습을 6분, 확장 활동을 4분으로 배분합니다. 도전 과제는 조기 완료자 또는 교육 후 복습용입니다. 확장 활동을 기존 실습 뒤에 모두 추가하지 않습니다.

## 상황과 목표

**장비 데이터의 역할 구분**을 수행합니다. 시작 파일은 `checkpoints/01_layout.usda`입니다. Python 예제는 Script Editor에서 `00_start_here.py`를 먼저 실행합니다. 원본 체크포인트는 저장하지 않고 결과를 outputs에 보관합니다.

## 가이드 실습

1. 공통 장면에서 CAD 장비, Workpiece, StatusLamp를 각각 선택한다.
2. 형상·물리·상태 중 각 객체가 맡은 역할을 적는다.
3. 실제 장비에서 가져와야 할 데이터와 지금 가상으로 만든 데이터를 나눠 적는다.

## 생각해 보기

형상이 정교하면 Digital Twin의 상태 값도 실제 값인가?

팀원과 예상 결과를 적고 관찰 결과를 비교합니다. 해설은 강사와 함께 확인합니다.

## 자주 발생하는 문제

증상: 상태 표시구를 실제 센서로 설명함

복구: CSV 값의 source를 확인하고 합성 데이터라고 표시한다.

## 선택 도전

전공에서 다루는 설비 하나를 골라 입력 데이터 3종, 표시 방법, 필요한 주기를 정한다.

## 제출 및 통과 기준

객체별 역할표와 실제 연동에 필요한 입력 목록를 제출합니다. 결과만 보여주지 않고 설정 또는 데이터가 결과에 영향을 준 이유를 한 문장으로 설명하면 완료합니다.
