# Day 1 Part 1 · Orientation

배정 20분: 설명 10분, 가이드 실습 10분. 준비 자료: 루트 README, `docs/SETUP.md`, `docs/WORKSHEET.md`.

## 목표와 개념

완료 시 CAD 장비가 들어 있는 USD Stage를 열고, 수업 마지막에 만들 상태 표시 결과를 설명할 수 있습니다. Stage는 합성된 장면, Prim은 장면의 객체, Layer는 장면 의견을 저장하는 단위입니다. Python 초급자를 위해 코드의 경로·숫자·문자열 변경부터 시작합니다.

## 따라하기

1. 실습 기록지에 이름, 앱 버전, GPU, Python 경험을 적습니다.
2. 저장소에서 `day1`, `day2`, `shared`, `scripts`, `checkpoints`를 찾아 역할을 말합니다.
3. Isaac Sim에서 `checkpoints/01_layout.usda`를 열고 `/World/Camera`를 선택합니다.
4. 장비, 파란 작업물, 상태 표시구를 각각 가리킵니다.
5. 강사의 `04_status.usda` 완성 예시를 보고 가상 온도와 표시 색의 연결을 설명합니다. 이후 01을 다시 엽니다.

## 완료 확인

- 장면이 열리고 부품이 보입니다.
- “실제 설비 연동 없이 가상 데이터를 표시한다”는 범위를 설명합니다.
- 제출: 환경 정보 및 전체 화면 캡처 1장.

오류가 있으면 SETUP의 문제 해결표로 해결하고, GPU 실행이 어려운 교육생은 짝 실습으로 진행합니다.
