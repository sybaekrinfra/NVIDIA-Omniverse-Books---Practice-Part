# D1P2 확장 실습 · UI 조작과 좌표 읽기

이 실습은 기존 Part 시간 안에서 선택해 진행합니다. 기존 기본 실습을 12분, 확장 활동을 8분으로 배분합니다. 도전 과제는 조기 완료자 또는 교육 후 복습용입니다. 확장 활동을 기존 실습 뒤에 모두 추가하지 않습니다.

## 상황과 목표

**카메라와 객체 이동 비교**을 수행합니다. 시작 파일은 `checkpoints/01_layout.usda`입니다. Python 예제는 Script Editor에서 `00_start_here.py`를 먼저 실행합니다. 원본 체크포인트는 저장하지 않고 결과를 outputs에 보관합니다.

## 가이드 실습

1. Workpiece의 Translate (1,0,1.5)를 기록한다.
2. 카메라만 이동한 뒤 값이 유지되는지 확인한다.
3. Workpiece X를 1.5로 바꾸고 값과 화면의 변화를 비교한다.
4. Undo 후 Size=1, Scale=0.2에서 실제 한 변 길이를 계산한다.

## 생각해 보기

화면에서 작아진 물체의 Scale도 반드시 작아졌는가?

답을 보기 전에 팀원과 예상 결과를 적습니다. [강사용 해설](../../instructor/EXPANDED_ANSWERS.md#d1p2)에서 비교할 수 있습니다.

## 자주 발생하는 문제

증상: Viewport 위치만 보고 좌표를 판단함

복구: Stage에서 정확한 Prim을 선택하고 Translate를 읽는다.

## 선택 도전

Equipment 래퍼를 0.5m 옮기고 하위 Prim의 로컬 값과 월드 위치가 다른 이유를 설명한다.

## 제출 및 통과 기준

카메라 이동/객체 이동의 수치 비교표를 제출합니다. 결과만 보여주지 않고 설정 또는 데이터가 결과에 영향을 준 이유를 한 문장으로 설명하면 완료합니다.
