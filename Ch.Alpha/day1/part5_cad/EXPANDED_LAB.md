# D1P5 확장 실습 · CAD 크기 검수와 오류 찾기

이 실습은 기존 Part 시간 안에서 선택해 진행합니다. 기존 기본 실습을 25분, 확장 활동을 20분으로 배분합니다. 도전 과제는 조기 완료자 또는 교육 후 복습용입니다. 확장 활동을 기존 실습 뒤에 모두 추가하지 않습니다.

## 상황과 목표

**1,000배 단위 오류 진단**을 수행합니다. 시작 파일은 `checkpoints/10_fault_units.usda`입니다. Python 예제는 해당 파일 전체를 Script Editor에서 바로 실행합니다. 원본 체크포인트는 저장하지 않고 결과를 outputs에 보관합니다.

## 가이드 실습

1. 정상 CAD의 높이가 약 2.108m임을 확인한다.
2. 10을 열고 08_check_readiness.py를 실행한다.
3. Equipment의 Scale과 바운드 높이를 확인한다. 약 0.002108m로 작아진 상태이다.
4. Equipment의 Scale을 (1,1,1)로 고친다.
5. 다시 검사하여 크기 항목이 PASS인지 확인한다. metersPerUnit=1은 바꾸지 않는다.

## 생각해 보기

metersPerUnit=1만 확인하면 실물 크기 검수가 끝나는가?

팀원과 예상 결과를 적고 관찰 결과를 비교합니다. 해설은 강사와 함께 확인합니다.

## 자주 발생하는 문제

증상: 작은 장비를 확대해서 정상 크기로 오인

복구: 카메라 대신 경계 크기와 Scale 수치로 판단한다.

## 선택 도전

Measure, Pivot, Section 중 사용 가능한 도구 하나로 기계 설계 검토 질문을 만든다.

## 제출 및 통과 기준

오류 수치·원인·수정 수치의 3열 기록를 제출합니다. 결과만 보여주지 않고 설정 또는 데이터가 결과에 영향을 준 이유를 한 문장으로 설명하면 완료합니다.
