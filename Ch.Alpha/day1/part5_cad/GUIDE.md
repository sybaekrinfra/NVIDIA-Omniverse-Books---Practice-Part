# Day 1 Part 5 · CAD 데이터와 Omniverse 기능

배정 90분: 설명 45분, 실습 45분. 입력: `shared/assets/cad/BX200L-C001.stp`, `.usd`, `BX200L-C_F-E.pdf`.

## 목표와 개념

CAD에서 넘어온 형상·조립 계층·단위·축을 확인합니다. CAD Import와 이미 변환된 USD Open은 구별합니다. 이 로봇 CAD는 기계 장비 형상 사례로만 사용합니다.

## 따라하기

1. 강사가 CAD Converter 사용 가능 여부를 확인합니다. 가능하면 STP를 Import하여 `outputs/cad_import.usd`로 변환합니다. 입력·출력 경로, 단위 옵션, 사용 변환기를 기록합니다.
2. 변환기가 없으면 제공 USD를 열고 기록지에 “기변환 USD 활용”이라고 씁니다.
3. defaultPrim, upAxis, metersPerUnit, 장비 높이 및 계층을 확인합니다. 제공 USD는 Z-up, 1m/unit이며 바운드 높이는 약 2.108m입니다. 새 변환 결과는 이 값과 비교합니다.
4. Measure가 제공되면 외형 높이를 측정합니다. 도면의 치수 방향·대상과 같은지 먼저 확인합니다. 바운드 높이는 정밀 CAD 치수 검증을 대신하지 않습니다.
5. Pivot 도구가 있으면 **복사한 장면**에서 회전 중심을 바꿔 회전 차이를 관찰하고 Undo합니다.
6. Section 도구가 있으면 단면을 이동하며 내부 구조를 관찰합니다. 절단면 표시가 원본 메시를 삭제하는지 구별합니다.
7. 도구가 없으면 Script Editor에서 00 실행 후 제공 체크포인트를 열고 01로 경계 크기를 출력합니다. Pivot은 강사 시연, Section은 개념 설명으로 대체하고 기록합니다.

## 완료 확인

제출: Import 여부, 변환기 이름, 단위/축/크기, 계층 화면, 사용 가능한 기능 및 대체 활동. CAD 원본과 변환본을 구분하고 크기 오류를 확인하면 통과합니다.

단위를 맞출 때 metadata만 바꾸면 좌표 수치가 환산되지 않습니다. 원본을 보존하고 변환기 단위 설정 또는 래퍼 Xform Scale을 사용한 후 실제 크기를 다시 측정합니다.
