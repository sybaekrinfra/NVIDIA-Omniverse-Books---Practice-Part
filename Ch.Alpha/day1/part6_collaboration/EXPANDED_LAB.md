# D1P6 확장 실습 · 설계팀과 검토팀의 Layer 분업

이 실습은 기존 Part 시간 안에서 선택해 진행합니다. 기존 기본 실습을 32분, 확장 활동을 20분으로 배분합니다. 도전 과제는 조기 완료자 또는 교육 후 복습용입니다. 확장 활동을 기존 실습 뒤에 모두 추가하지 않습니다.

## 상황과 목표

**배치 수정과 검토 색 동시 반영**을 수행합니다. 시작 파일은 `checkpoints/02_structured.usda`입니다. Python 예제는 Script Editor에서 `00_start_here.py`를 먼저 실행합니다. 원본 체크포인트는 저장하지 않고 결과를 outputs에 보관합니다.

## 가이드 실습

1. usd_basics 폴더 전체를 outputs/team_demo로 복사한다.
2. A는 assembly의 위치, B는 review의 색을 각각 수정한다.
3. review를 다시 열어 두 변경이 합성되는지 확인한다.
4. 둘이 같은 속성을 쓰는 경우와 서로 다른 속성을 쓰는 경우를 비교한다.
5. 폴더 전체를 다른 위치로 옮겨 상대 경로가 유지되는지 재열기한다.

## 생각해 보기

Git 파일 이력과 Nucleus Live Session은 같은 기능인가?

팀원과 예상 결과를 적고 관찰 결과를 비교합니다. 해설은 강사와 함께 확인합니다.

## 자주 발생하는 문제

증상: 루트 파일만 전달하여 참조 끊김

복구: 의존 폴더 전체를 함께 전달한다.

## 선택 도전

서버가 있으면 별도 계정의 읽기/쓰기 권한과 변경 후 Reload를 검증한다.

## 제출 및 통과 기준

담당 Layer 표, 합성 화면, 이동 후 재열기 결과를 제출합니다. 결과만 보여주지 않고 설정 또는 데이터가 결과에 영향을 준 이유를 한 문장으로 설명하면 완료합니다.
